# oplus-votable

面向具有 OPLUS Votable 接口的 Android 设备的 Root 模块，通过 UFCS / PPS 电流投票节点进行自适应充电控制，并提供本地 WebUI 查看状态、调整参数和读取日志。

**当前版本：0.8.8-protocol-defaults。** 安装包请从 [GitHub Releases](https://github.com/NymphQAQ/oplus-votable/releases) 下载。

## 使用前提与注意事项

- 设备已取得 Root 权限，并支持安装 Magisk / KernelSU 系模块。
- 内核提供 `/proc/oplus-votable/UFCS_CURR` 或 `/proc/oplus-votable/PPS_CURR`，以及对应的 OPLUS MMS 协议状态接口。不同设备和固件不保证兼容。
- WebUI 需要模块管理器提供 `window.ksu.exec` 接口，请在支持该接口的管理器中打开。
- 本模块会修改充电电流投票；设置值不是充电器实际输出电流，也不保证达到对应功率。
- 当前没有启用本模块自身的温度限制。使用时留意设备温度和电压，异常时及时关闭控制或断开充电器。

## 功能

- UFCS / PPS 独立协议开关、设定电压和投票上限；各有一键恢复默认按钮，保存后回读确认。
- 根据电池电压动态调整投票目标。协议断开、切换或关闭控制时撤销本模块自己的强制投票。
- VOOC / SUPERVOOC 仅进行只读识别和诊断，不主动控制电流。
- 概览显示协议、电池状态，以及四项协商读数：实时 USB 输入电压、USB 报告电压上限、USB 输入策略限额、模块当前投票目标。
- 日志独立读取，支持当前 / 历史日志、搜索、筛选和复制。
- 只读 Votable 浏览与当前协议诊断。

## 安装与升级

1. 在 [Releases](https://github.com/NymphQAQ/oplus-votable/releases) 下载 `oplus-votable-0.8.8-protocol-defaults.zip`，不要使用 GitHub 自动生成的源码 ZIP 作为模块安装包。
2. 通过支持的 Root 模块管理器安装 ZIP，按管理器要求重启手机。
3. 从模块管理器打开 WebUI，在“控制”页设置 UFCS / PPS 参数。

自动监测及 UFCS / PPS 协议开关默认开启。只有协议在线且对应开关开启时才接管电流投票。

有效的旧设置保存在 `/data/adb/oplus-votable/`，升级后保留。需要应用新版默认参数时，在对应协议页点击“恢复默认”；该按钮只重置本协议的电压和投票上限，不改变其它协议或高级参数。

从 0.8.7 升级时，安装脚本会移除旧版温度写入开关，使旧后台停止写入。0.8.8 不包含温度监测入口或固定温度写入脚本。

## 默认参数

| 协议 | 默认设定电压 | 默认投票上限 | 电压可调范围 | 投票上限可调范围 |
| --- | --- | --- | --- | --- |
| UFCS | 4560 mV | 9000 mA | 3800–4560 mV | 1000–13500 mA |
| PPS | 4500 mV | 5000 mA | 3800–4560 mV | 1000–5800 mA |

全局高级电流参数：

| 参数 | 默认值 | 可调范围 |
| --- | --- | --- |
| 投票初始值 | 1000 mA | 1000–10000 mA |
| 监控时间 | 100 ms | 20–200 ms |
| 提升步进 | 100 mA | 10–500 mA |
| 降低步进 | 500 mA | 100–1000 mA |
| 升流截止压差 | -50 mV | -100–0 mV |

控制规则：电压低于“设定电压 + 升流截止压差”时增加投票值，超过设定电压时降低投票值，两者之间保持不变。投票值不低于 1000 mA，也不超过对应协议的投票上限。

## 开发与构建

本项目使用原生 Shell、JavaScript 和 Node.js 内置模块，无需安装 npm 依赖。开发电脑需要 Node.js、POSIX Shell、`zip` 和 `unzip`。

运行测试：

```sh
node --test test/*.mjs
```

构建模块安装包：

```sh
node build.mjs
```

输出文件：`dist/oplus-votable-0.8.8-protocol-defaults.zip`。构建脚本仅打包白名单内的运行文件，并校验 ZIP 内容。

测试使用模拟节点和临时目录验证控制算法、参数持久化、WebUI 行为及升级清理；通过测试不代表已验证所有设备的充电硬件行为。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `module.prop` | 模块信息与版本 |
| `service.sh` | 开机服务入口 |
| `charge-test.sh` | 自适应电流控制、参数与租约恢复 |
| `watchdog.sh` | 本模块控制租约守护 |
| `customize.sh` | 升级时撤销旧版温度写入开关 |
| `uninstall.sh` | 卸载清理入口 |
| `webroot/` | WebUI 与固定路径只读接口 |
| `control-policy.mjs` | 离线控制算法模型 |
| `test/` | 自动化测试 |
| `build.mjs` | 模块 ZIP 打包与内容校验 |

## 0.8.8 更新

- 撤销 0.8.7 的温度监测与固定温度写入功能。
